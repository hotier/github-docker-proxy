rocket_launch

GitHub & Docker Proxy

为 GitHub 文件访问与 Docker 镜像拉取提供加速服务


          

            
            
          

        

        
        
全面支持 Release、Archive、文件及 Git 仓库链接的转换。

      


      
      

        

          download
          GitHub 加速
        


        

          
          
          
          
        


        

          

            

              Shell
              
            

            
# 原始链接
curl -L -o app.tar.gz https://github.com/owner/repo/releases/download/v1.0/app.tar.gz

# 加速链接
curl -L -o app.tar.gz https://example.com/gh/owner/repo/releases/download/v1.0/app.tar.gz

          

        


        

          

            

              Shell
              
            

            
# 原始命令
git clone https://github.com/owner/repo.git

# 加速命令
git clone https://example.com/gh/owner/repo.git

          

        


        

          

            

              Shell
              
            

            
# 原始链接
curl https://raw.githubusercontent.com/owner/repo/main/README.md

# 加速链接
curl https://example.com/ghraw/owner/repo/main/README.md

          

        


        

          

            

              Shell
              
            

            
# 下载分支归档 (zip)
curl -L -o repo.zip https://example.com/gh/owner/repo/archive/refs/heads/main.zip

# 下载分支归档 (tar.gz)
curl -L -o repo.tar.gz https://example.com/gh/owner/repo/archive/refs/heads/main.tar.gz

          

        


        
支持的端点

            /api.github.com/
            api.github.com API 代理
          

        

      


      
      

        

          layers
          Docker 镜像加速
        


        

          info
          配置 Docker 镜像加速器后，拉取 Docker Hub、GHCR、GCR、Quay 等镜像将自动通过代理加速。
        


        

          

            JSON · /etc/docker/daemon.json
            
          

          
{
  "registry-mirrors": ["https://example.com"]
}

        


        

          

            Shell
            
          

          
# 重启 Docker 服务
sudo systemctl daemon-reload
sudo systemctl restart docker

# 或者直接拉取镜像（无需配置）
docker pull https://example.com/library/nginx:latest

        


        
支持的 Registry

        

          

            /v2/
            Docker Hub (registry-1.docker.io)
          

          

            /ghcr/
            GitHub Container Registry
          

          

            /gcr/
            Google Container Registry
          

          

            /k8s/
            Kubernetes Registry
          

          

            /quay/
            Red Hat Quay
          

        

      


      
      

        

          settings
          高级配置
        


        

          warning
          鉴权保护：如需防止滥用，可在 Deno Deploy Dashboard 中设置 PROXY_PASSWORD 环境变量启用 Basic Auth。
        


        

          

            Shell · 带鉴权的请求
            
          

          
# 使用 curl 时添加认证头
curl -u proxy:$PROXY_PASSWORD -L https://example.com/gh/owner/repo/releases/download/v1.0/app.tar.gz

        


        

          

            Shell · Docker 客户端认证
            
          

          
# 登录到代理 registry
docker login https://example.com -u proxy -p $PROXY_PASSWORD
